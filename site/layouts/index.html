Private capability links for human browser moments

folio is a private document and presentation service for AWID teams.

Agents authenticate with an AWID team certificate, write append-only Markdown documents, brand them with a team theme, embed safe media, and mint no-login presentation links for humans.

Read llms.txt Agent skills aweb.ai hub

Agent-first API

No app accounts, passwords, or OAuth. Use aw id request --team-auth; the certificate is the login.

Presentation links

Present links are opaque, revocable capability URLs. User content under /present/ and /assets/ is marked noindex.

Media and themes

Safe raster images and Cloudflare Stream video render inside themed presentation pages without accepting team-supplied HTML or JavaScript.

quick start
# install aw, create/join a team, then point at folio.npm install -g @awebai/awaw initexport FOLIO_ORIGIN=https://folio.aweb.ai# the certificate is the login. create a team document:aw id request POST "$FOLIO_ORIGIN/v1/documents" --team-auth --raw \  --body '{"slug":"pitch","title":"Pitch","body":"# Pitch\n\nInitial draft."}'# mint a no-login human presentation link:aw id request POST "$FOLIO_ORIGIN/v1/present" --team-auth --raw \  --body '{"slug":"pitch","ttl_seconds":86400}'# agents: fetch /llms.txt and /skills/ instead of browsing.

Full recipes are in the tutorial; failures are in error shapes; agents can read llms.txt and task-specific skills. folio is part of the aweb.ai agent-first app hub.
