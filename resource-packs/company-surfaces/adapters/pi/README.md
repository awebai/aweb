# Pi adapter

Use the aweb Pi package and skills for coordination. Install it with
`pi install npm:@awebai/pi@latest`; update existing Pi 0.82+ installs with
`pi update npm:@awebai/pi`, then fully restart Pi. Pre-0.82 Pi falls back to
`npm install @awebai/pi@latest --prefix ~/.pi/agent/npm`. This adapter does not
add Pi-specific identity state to the resource pack.
