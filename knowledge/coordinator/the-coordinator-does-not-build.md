Ruled by the operator on 2026-10-21, when urgent implementation work landed on
a coordinator: "pick an owner for it, do not build it yourself. i need your
context for coordinating". The same reasoning, the same day, set review routing:
"you do not need to be copied in all reviews, as long as the agent being
reviewed gets them. we need to save your contexxt."

## Decision

- New work, however urgent, gets an owner seat. The coordinator writes the
  brief and routes; it does not implement.
- Reviewers send verdicts to the author. Authors mail the coordinator only for
  landing requests, rulings and unresolved blockers, not for status.
- Spend the coordinator's context on what only it can do: sequencing,
  cross-lane rulings, staffing and landing.
