# Lessons

* [Converged decisions stay frozen](converged-decisions-stay-frozen.md) - Once the team has converged and committed on a functionally fine choice, do not reopen it for a marginal detail; a coordinator's flip-flop costs more than the gain.
* [Verify business facts; consolidate before cutting](verify-business-facts-and-consolidate-before-cutting.md) - Never justify a cut with an assumed product or roadmap fact, and treat messy-but-needed machinery as something to consolidate, not remove.
* [Correctness over momentum](correctness-over-momentum.md) - Activity is not progress; write and pressure-test plans for irreversible steps instead of manufacturing work to avoid idleness.
* [Drive coordination to done](drive-coordination-to-done.md) - Decide what is yours, track work by next step and done-signal, hold the full scope as tracked work, and escalate only genuine product or authority forks.
* [A harness must be shown to fail](a-harness-must-be-shown-to-fail.md) - A red counts only if its text names the property; a zero counts only if the detector was shown positive; a validated detector is not a valid experiment.
* [Review every site on both axes](review-every-site-on-both-axes.md) - Verify the change's own purpose at every site, then the standard dimensions at each site; the miss is always an adjacent dimension at an outlier site.
* [Reproduce and read the first error before attributing a regression](reproduce-before-attributing-a-regression.md) - A bisect bounds the delta, not the commit; raise the bar when the suspect is your own code.
* [A live result outranks a theory](a-live-result-outranks-a-theory.md) - When accounts of a testable fact disagree, even with the nominal decision owner, the passing end-to-end proof decides.
* [Verify a cross-team recipient like a SHA](verify-a-cross-team-recipient-like-a-sha.md) - Address teammates in other teams by verified domain and roster alias; a delivered send proves nothing about who you meant.
* [Never kill by pattern on a shared host](never-pattern-kill-on-a-shared-host.md) - Agents on one host run as the same Unix user, so pkill -f or killall can stop other agents' work; on macOS pkill stops reading options at the first pattern, so a trailing option becomes a second pattern. Stop only your own jobs, through the harness or a verified PID.
* [Review a change against its existing consumers](review-a-change-against-its-existing-consumers.md) - A change is not proven by its own new test; when it alters a contract, grep for tests and callers of the old behaviour and run the changed packages' tests, and when main brings callers of anything the branch changed, a merge ACK needs an import or collection run at the exact merged head.
* [Focused proof includes the contract guards](focused-proof-includes-the-contract-guards.md) - When choosing focused tests, enumerate the contract surfaces a change introduces and run each surface's independent guard (reviewed route-scope inventories, the packaged migration chain, downstream byte-identical goldens), not only the behavioural tests.
* [Identity and routing review needs the real client](identity-and-routing-review-needs-the-real-client.md) - When the server re-derives something the client signed (recipient, address, conversation), a green whole server suite is not review evidence; the real CLI journey and the federation end-to-end set must run, and the reviewer states which gate stages it did not cover.
* [A projection governs the whole query and the whole result](a-projection-governs-the-whole-query-and-result.md) - When a query masks or narrows data for authorization, every join and filter must use the projected value and the whole returned object must be whitelisted; projecting one field while joining on the raw column, or narrowing only the value inside a record envelope, leaks or corrupts.
* [A test result belongs to the bytes that ran](a-test-result-belongs-to-the-bytes-that-ran.md) - A queued run reads the working tree when it executes, not when it was queued; restoring a mutation from HEAD wipes uncommitted edits; and same-second, same-size Python mutations can reuse stale bytecode. Bind every result to the exact bytes executed before calling it exact-SHA evidence.
* [Elapsed time is a test input](elapsed-time-is-a-test-input.md) - Vary how long a failure takes, not only what it returns: a fast failure hid a retry storm that a realistic ten-second failure exposed, and a fixed wall-clock barrier failed only on slow hosts; inject latency into the test's own stub to reproduce, then wait on progress with a stall bound and a cap.
* [Lock order in authority and approval transactions](lock-order-in-authority-and-approval-transactions.md) - Lock authority before the approvals it can revoke, prelock row sets explicitly in a sorted order, recheck expiry and authority after every blocking wait, and prepare every lock a later read will take; each rule cost a deadlock or a refusal that came too late.
* [Self-addressed mail does not wake a session](self-addressed-mail-does-not-wake-a-session.md) - The aw wake resolvers and the channel deliberately skip self-authored mail and chat, so mailing yourself when a queued job finishes never resumes you; keep the job's exact head and result artifacts so the result can be recovered on the next real wake.
* [Secret history sweeps define their coverage](secret-history-sweeps-define-their-coverage.md) - A history sweep covers only the refs it enumerates, a detector is evidence only on the credential forms it was shown to catch, and an "in-memory" scan can still spill to disk; name the ref universe, validate detectors on the actual forms, and check every persistence boundary.
