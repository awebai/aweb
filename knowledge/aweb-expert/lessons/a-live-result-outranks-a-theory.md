Recorded by the OSS coordinator role on 2026-06-18. Twice in one day two
coordinators argued from theory that a deployed verifier reconstructed an
internal path and that a client therefore had to be "fixed" — which would have
re-broken a path a live emit had already proven end to end. The disagreement
was about a testable fact; the live emit, the source and the guard test settled
it.

# How to apply

- When accounts of a testable fact disagree, run the test. The passing
  end-to-end result is the arbiter, whoever holds the pen on the decision.
- Reconcile to one written truth backed by code, result and test before
  anything else moves; a contradiction left standing propagates.
- The protocol-specific rule that came out of this episode is recorded by the
  protocol expert as the decision that the signed request target is the external
  path.
