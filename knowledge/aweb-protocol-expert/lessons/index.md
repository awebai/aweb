# Lessons

* [Delivery receipts and stream health in channel adapters](delivery-receipts-and-stream-health.md) - A transport send is not a delivery receipt; acknowledge only at a real host acceptance boundary, keep event lanes independent, and declare a stream healthy only after live evidence.
* [tmux isolation for agent runtimes](tmux-isolation-for-agent-runtimes.md) - Per-team sockets and a guarded tmux on the path are the runtime-agnostic protections; an inherited tmux variable can hide the server that holds the whole fleet.
* [Gate before the point of no return](gate-before-the-point-of-no-return.md) - Availability and authorization gates belong on admission and on the last step before an irreversible effect; once bytes are sent or a credential issued, the record of that consequence commits in the same transaction and fails only on its own write. A "stricter" condition that gates the record afterwards strands the effect.
* [Accepted guarantees change only by ruling](accepted-guarantees-change-only-by-ruling.md) - When an implementation cannot meet a promise in an accepted design, do not align the text down to the implementation; quote the promise and get a ruling. A service-held verification summary or a keyed digest whose key is later destroyed cannot give independent later verification.
* [Unauthenticated input must not drive remote work](unauthenticated-input-must-not-drive-remote-work.md) - Order checks so cheap local verification and admission controls run before per-request remote lookups; a remote check moved earlier must not create exits that skip existing admission controls, and lookups driven by caller-chosen input cache their negative answers.
* [Evidence freshness must survive lock waits](evidence-freshness-survives-lock-waits.md) - Moving a remote authority lookup out of a transaction must not move the freshness decision before the wait; carry the producer's original expiry across the lock wait and check it after acquiring the lock, never restarting a window on receipt, cache hit or lock acquisition.
* [A time budget covers the whole operation](a-time-budget-covers-the-whole-operation.md) - A total operation budget starts before discovery and client construction, and an optional or soft refresh still needs a short total bound; a fallback policy limits the error, not the time it costs. A deadline red proves a hidden cap, not the cause of a historical stall.
* [Shared vectors prove only what they pin](shared-vectors-prove-only-what-they-pin.md) - Check each single-fault negative vector by skipping its own check, probe primitive boundaries independently of the corpus in every language, and run every consumer of a vector change with its own prerequisites and policy inputs; a shared corpus does not by itself make accepted input domains equal.
* [Vary independent assurance dimensions in review](vary-independent-assurance-dimensions.md) - To test an assurance label, find the fact that should authorise it, hold that fact constant and vary a neighbouring property that should not matter; an implementation can match every example while deriving the label from the wrong fact.
* [Admission is not the effect transaction](admission-is-not-the-effect-transaction.md) - A request guard that returns verified authorization does not own the handler's transaction; an audit or outbox write must receive the handler's actual effect transaction, network evidence is fetched before effect locks, and no request-wide wrapper follows from this.
* [Docker published ports are not a stable test path](docker-published-ports-in-tests.md) - On Docker Desktop a reused published port can stop forwarding after its backend is replaced, and a published port reachable through the host gateway may refuse through the bridge gateway; use daemon-assigned ports or the compose network's internal endpoints, and prove the route with controls instead of adding retries or longer timeouts.
* [Local stop is not new binding authority](local-stop-is-not-new-binding-authority.md) - Preserve the existing account-owned stop after membership loss without relaxing portable signed unbind or granting new binding authority.
* [Frozen vectors need a real consumer](frozen-vectors-need-a-real-consumer.md) - An unused hypothesis matrix adds a parallel specification; under acmj's frozen-vector policy ordinary consumer tests carry design acceptance.
* [SSE cleanup is cancelled on client disconnect](sse-cleanup-is-cancelled-on-disconnect.md) - Under uvicorn (ASGI spec 2.3) Starlette cancels the response task group on http.disconnect, so every await in an SSE generator's finally is cancelled too; cleanup must run under anyio.CancelScope(shield=True) or be synchronous.
* [A mounted app gets no lifespan](a-mounted-app-gets-no-lifespan.md) - A host that mounts the aweb app as a sub-app never runs its lifespan, so a process service started in create_app's lifespan never runs in that host while every OSS test stays green; a new lifespan service needs a public start/stop for mounting hosts, a loud signal when absent, and the mounting host's matching change in the same release.
* [Process helpers keep no idle tasks](process-helpers-keep-no-idle-tasks.md) - A process-level helper in shared library code runs its background task only while it has work; an idle forever-waiting task outlives host runtimes that close later than their event loop's task checks, and only the host's leak check catches it.
* [Removing an implicit side effect is a contract change](removing-an-implicit-side-effect-is-a-contract-change.md) - A request-path side effect can be the only recovery path for hosts that mount aweb without its lifespan, and a released contract may promise it; removing it keeps the default automatic, gives an explicit opt-out for hosts that own the duty, and never hands hosts a new duty by docstring.
* [Measuring and testing hot-path changes across repositories](measuring-hot-path-changes.md) - OSS e2ee read-trust and listener-restart tests ERROR in setup unless make test-node-deps has run, which hides the sender-membership coverage a messaging change needs, so count them as not run; for a like-for-like before/after under an embedding host, put an exported baseline or the OSS tree first on PYTHONPATH and verify module paths by import.
