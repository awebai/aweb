# Decisions

* [Team certificates are controller-only](team-certificates-are-controller-only.md) - Registering and revoking a team certificate is authorised by the team controller alone; an issuer column and revoke-broadening were investigated and declined until member-mediated invites exist.
* [The signed request target is the external path](signed-request-target-is-the-external-path.md) - The team-auth envelope signs the actual external request target including any mount prefix; the verifier reads the raw path and never strips a prefix.
* [Agent-runtime launch is written once](agent-runtime-launch-written-once.md) - Team up, single add-with-start and remove share one per-agent launch and teardown primitive in the aw CLI.
* [Home and work isolation in aw team commands](home-and-work-isolation-in-aw-team-commands.md) - An aw-created agent home never hosts git work; every agent gets a worktree, and main is reached only through an explicitly named handle.
* [Released clients are a permanent constraint](released-clients-are-a-permanent-constraint.md) - The server accepts what published clients send until it is measured that nothing sends it; contract changes are additive by default.
* [Identity selection is one precedence rule](identity-selection-is-one-precedence-rule.md) - Every aw command selects its principal the same way (--identity-home, else AWEB_IDENTITY_HOME, else the current directory's .aw) and a selected folder never falls back to the current directory; a per-command allowlist was removed as "not security", and the peer trust store stays user-level.
* [Codex live delivery is the OATS wake](codex-live-delivery-is-the-oats-wake.md) - Nothing aweb ships recommends `aw run codex`; Codex gets live mail and chat delivery through the OATS host wake broker, and standalone Codex reads when asked. A command proven to work is not thereby the supported journey.
* [Tests exercise the real authority](tests-exercise-the-real-authority.md) - Mocks are acceptable only rarely and almost never in end-to-end tests; a test must run the component that decides the result, the suite should stay under an hour, and code or tests left unused by a change are deleted in that change.
* [Release candidates keep dependency floors](release-candidates-keep-dependency-floors.md) - An RC tree carries >=X.Y.ZrcN floors and the final carries >=X.Y.Z, moved only for packages promoted in the same trees; exact pins were rejected because they couple independent releases. Release policy is proven at the real entry point with a really stamped tree.
* [Key authority history spans every path to the key](key-authority-history-spans-every-path.md) - Revocation and key-identity history are keyed by key identity and consulted by every insert and lookup that can reach the key, across table versions, tenants, origins, uninstall and reinstall; revocation is one-way and rotation uses a new key id.
* [Address history does not prove identity continuity](address-history-does-not-prove-identity-continuity.md) - The identity registry rewrites an address's did_aw in place and keeps its created_at, so no timestamp shows who held an address earlier; legacy address-only contacts are left inert rather than bound by a guessed backfill, and every contact path writes the exact binding at creation.
* [Credential lifetime is optional team policy](credential-lifetime-is-optional-team-policy.md) - Certificate and grant expiry is a per-team setting with no expiry by default and live revocation as the primary control; a renewal that replaces a certificate does not end the grants it issued, and no renewal or policy change ever extends a deadline. Ruled, not yet shipped.
* [Test databases run on tmpfs](test-databases-run-on-tmpfs.md) - Intermittent PostgreSQL stalls in the test suite are fixed by putting every test database on tmpfs, never by raising a timeout or skipping; the mount must be verified, not assumed. Accepted, not yet landed.
